# IntelliWatch Frontend Dashboard

## Technology Direction
- **Framework**: React (Vite / Next.js)
- **UI & Styling**: Modern CSS with clean glassmorphic industrial aesthetics
- **Live Streams**: WebRTC / HLS / WebSocket frame streaming
- **Visual Analytics**: Interactive event timeline, heatmaps, and zone configuration canvas
