# IntelliWatch Data Store

This directory contains runtime media files, video streams, and incident captures:

- `input/`: Incoming raw CCTV video files, RTSP test clips, or uploaded footage.
- `output/`: Processed videos with visual overlays, bounding boxes, and metadata renders.
- `samples/`: Lightweight benchmark clips for automated tests and pipeline validation.

*Note: All media files in this folder are git-ignored.*
